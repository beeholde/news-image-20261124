Sum up 24 November 2026's world news in one image: a broadsheet front page
("THE WORLD TODAY") with 33 dated stories across 8 regions — the CAS ruling
on the AFCON title due today, the FIDE World Chess Championship Game 1 in
Geneva, Champions League Matchday 5, the Beaver Supermoon, Tokyo's market
reopen, Monday's record Wall Street rally, and the US–Iran war into day 270.
Every story carries an explicit day tag (TUE = today, MON/SUN/SAT/FRI =
earlier), and a DATE CHECK box states what is — and is not — Tuesday's news.

## Run it

```sh
python3 main.py /output/entry.png
```

`main.py` is standard-library only: it verifies the embedded 1024×1024 PNG
(sha256 + 1 MiB cap) and copies it to the output path. Set `ENTRY_OUTPUT`
to choose a different destination.
